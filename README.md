# MikScrollingBattleTextOptions

Mirror of the `MikScrollingBattleTextOptions` folder from [pepopo978/Vanilla_MikScrollingBattleText](https://github.com/pepopo978/Vanilla_MikScrollingBattleText) (Mik's Scrolling Battle Text 4.43 for WoW 1.12 with Turtle WoW / OctoWoW spells). Requires https://github.com/Dinkleberrrg/MikScrollingBattleText.

No own code changes. The upstream repository contains two addon folders in one repository, which the Octo launcher cannot install. This repository holds just one folder (history preserved) so it can be added as a custom git addon:
`https://github.com/Dinkleberrrg/MikScrollingBattleTextOptions`
